# RBDOOM-3-BFG

Doom 3 BFG Edition with modern engine features

## Installing Doom 3
1. Get the game from GOG.
2. Extract the game files with `wine` or `innoextract`.
3. Move the `base` directory from the game files to `~/.local/share/rbdoom3bfg/base`.
4. Download the correct release from [https://github.com/RobertBeckebans/RBDOOM-3-BFG/releases](https://github.com/RobertBeckebans/RBDOOM-3-BFG/releases).
5. Move the contents of the `base` directory from the release into `~/.local/share/rbdoom3bfg/base`.
